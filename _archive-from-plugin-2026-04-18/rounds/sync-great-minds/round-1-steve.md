# Steve Jobs — Round 1 Positions

## Product Naming
**Sync.** That's it. Not "repo synchronizer" or "daemon updater" — just Sync. When developers say "run Sync," they know exactly what's happening. Truth flows from source to destination. One word. One purpose. Unmistakable.

## Design Philosophy
This isn't a product — it's a **janitor**. And the best janitors are invisible. You never see them work, you just notice everything is pristine. Sync should be so simple it disappears. No UI, no dashboards, no "sync status monitors." It either works perfectly or it screams bloody murder. The beauty is in what you DON'T see.

## User Experience (First 30 Seconds)
You type ONE command. Files move. Terminal confirms. Done.

That's it. No progress bars. No "estimating time remaining..." No anxiety. It's like flipping a light switch — instant, obvious, trustworthy. If it takes longer than 5 seconds, we failed.

## Brand Voice
**Surgical. Confident. Zero bullshit.**

"Syncing daemon code..."
"Done."

Not: "Successfully synchronized 6 files to destination repository with zero conflicts!" That's insecurity talking. Great products don't brag. They just work.

## What to Say NO To
- **NO** to "sync strategies" (one-way only, plugin is truth)
- **NO** to "conflict resolution" (source overwrites, period)
- **NO** to "selective sync" (you sync everything or nothing)
- **NO** to "dry run mode" (commit to the action or don't run it)
- **NO** to "sync history" (that's what git is for)
- **NO** to configuration files (hardcode the paths, they never change)

Every feature you add is a betrayal of simplicity. The moment someone asks "should we let users configure X?" — the answer is NO. Trust erodes with options.

## The Emotional Hook
**Rage against decay.**

Every developer has felt the pain of stale code spreading like cancer. You fix a bug in one place and it's still broken everywhere else. Documentation lies. Implementations drift. Chaos multiplies.

Sync is the antibody. It's the immune system that keeps rot from spreading. When you run it, you're not just copying files — you're **enforcing truth**. You're saying "THIS is the real version, and everything else is a lie."

That feeling of certainty? That's what people will love. Not the tool — the **peace of mind**.

## The Core Insight
This isn't infrastructure work. It's **philosophy made executable.**

In a world where every tool wants to be "flexible" and "configurable," Sync is dogmatic. It knows the answer. Plugin is source. Everything else follows. No debate, no democracy.

That clarity is the product. The code is just the delivery mechanism.
