## Accessibility

**Who's left out:**

- **Non-English speakers.** Idioms like "refuses to stay dead" may not translate.
- **Complete beginners.** Terms like "daemon," "systemd," "OOM killer" explained but still dense.
- **Screen readers.** Code blocks readable but heavy. No alt-text (though none needed — text-only).
- **Low-patience readers.** Long. 2000 words. Requires commitment.

**Who's served:**

- Engineers (obviously). Autonomous systems builders. DevOps folks.
- Technical founders learning to build resilient infrastructure.
- Anyone who's faced catastrophic failure and rebuilt.

**Gaps:**

- No visual learners support. Could use architecture diagram (v1 skipped deliberately per spec).
- Assumes familiarity with command-line concepts. "PID lockfile" explained but tersely.
- Western tech culture context (GitHub, cron, systemd). Not universal.

Not exclusionary by design. Just specific audience. Trade specificity for universality would weaken story.
