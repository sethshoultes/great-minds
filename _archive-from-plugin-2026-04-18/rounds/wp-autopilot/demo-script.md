# WP Autopilot — 2-Minute Demo Script

---

[SCREEN: WordPress admin dashboard, cluttered menus everywhere]

**NARRATOR:**
You've been staring at this for twenty minutes.

[SCREEN: Mouse hovers between Pages, Posts, Settings]

**NARRATOR:**
You know what you want to build. You just don't know where the hell WordPress hid it.

[SCREEN: Google search tab opens: "how to add contact page wordpress"]

**NARRATOR:**
So you Google. Read four different answers from 2017. Try three different menus.

[SCREEN: Back in WordPress, opening Pages > Add New]

**NARRATOR:**
And you still feel like you're doing it wrong.

---

[SCREEN: Plugin activates. Chat panel slides open]

**NARRATOR:**
What if you just... asked?

[SCREEN: Chat greeting appears: "What would you like to build?"]

**NARRATOR:**
No manual. No tutorial. Just this.

[SCREEN: Types "Add a contact page"]

**NARRATOR:**
You type what you want.

[SCREEN: Chat thinks, then responds: "I'll create a Contact page with a heading and paragraph. Proceed?"]

**NARRATOR:**
It tells you what it's about to do.

[SCREEN: Clicks "Proceed"]

**NARRATOR:**
You say yes.

[SCREEN: Page appears in admin. Title: "Contact". URL: /contact]

**NARRATOR:**
Done.

---

[SCREEN: Chat still open. Types "Put a contact form on it"]

**NARRATOR:**
But you're not done.

[SCREEN: Chat responds: "I'll activate Contact Form 7 and add a form block to your page. Proceed?"]

**NARRATOR:**
So you keep going.

[SCREEN: Clicks "Proceed". Page updates with form block]

**NARRATOR:**
No searching for plugins. No wondering if you installed the right one.

[SCREEN: Types "Change the homepage headline to Welcome to Great Minds"]

**NARRATOR:**
You just build.

[SCREEN: Chat responds: "I'll update your homepage title. Proceed?"]

[SCREEN: Clicks "Proceed". Homepage updates]

**NARRATOR:**
And it happens.

---

[SCREEN: Site preview opens. Contact page live. Homepage updated. Form working.]

**NARRATOR:**
Three requests. Two minutes. Zero shame.

[SCREEN: Chat panel closes. WordPress admin looks the same as always.]

**NARRATOR:**
WordPress didn't change.

[SCREEN: Chat panel reopens: "What would you like to build?"]

**NARRATOR:**
You did.

---

[SCREEN: Fade to plugin name: WP Autopilot]

**NARRATOR:**
WordPress without the manual.
