# Board Review: WP Autopilot
**Reviewer:** Shonda Rhimes
**Lens:** Narrative & Retention
**Date:** 2026-04-16

---

## Story Arc: 3/10

**Critical flaw: No journey.**

- Signup → aha moment is a flatline
- No onboarding narrative (just "enter API key")
- First chat greeting is generic instruction, not invitation
- No progressive disclosure of power
- User dropped into deep end with zero tutorial
- Missing: "Let me show you what we can do together" moment
- Missing: Success celebration after first action
- Missing: "What's next?" breadcrumbs

**What exists:**
- Settings page: sterile form
- Chat greeting: "What would you like to build?" (asks but doesn't inspire)
- Example prompt: one throwaway line
- Post-action: confirmation button (not a milestone)

**No emotional buildup. No payoff. No "I can't believe I just did that" moment.**

---

## Retention Hooks: 2/10

**Nothing brings people back.**

- Chat history dies in 1 hour (anti-retention)
- No progress tracking
- No "yesterday you built X, today let's Y"
- No "here's what you could do next" suggestions
- No email reminders
- No achievements/unlocks
- No social proof ("10K sites built this week")
- No evolving capability ("you've unlocked advanced features")

**Transient storage murders retention:**
- Lose context = lose investment
- Lose history = lose narrative thread
- User returns to blank slate every time
- No sense of progress

**Beta metrics will reveal this:**
- Target 50% next-day return
- Prediction: 15-20% actual
- Reason: nothing sticky

---

## Content Strategy: 1/10

**No flywheel. Zero content generation.**

- Plugin doesn't suggest what to build
- No showcase of user creations
- No library of popular patterns
- No "trending requests this week"
- No content recommendations based on site context
- No "other users also built..."

**Missed opportunities:**
- User creates Contact page → suggest About page
- User adds testimonials → suggest case studies section
- User builds service page → suggest pricing table
- Site lacks blog → nudge toward first post

**No virality:**
- No sharing mechanism
- No public gallery
- No "Built with WP Autopilot" badge
- User success invisible

---

## Emotional Cliffhangers: 4/10

**Weak hooks. No suspense.**

**What works:**
- Action confirmation creates micro-suspense ("Proceed?")
- "Thinking..." indicator builds anticipation
- Success message provides closure

**What's missing:**
- No "what if I..." prompts
- No "you're 2 actions away from a complete site" progress bar
- No "tomorrow I'll show you how to..." teasers
- No unfinished business ("your About page needs a hero image")
- No discovery loop ("did you know you can...?")
- No stakes ("your homepage is missing X, visitors might bounce")

**Chat ends flat:**
- User gets answer → done
- No "next episode" setup
- No reason to come back
- Session closes cold

---

## Narrative Gaps

**Onboarding:**
- API key setup has no story (just technical requirement)
- Should be: "Let's get you set up. You're 3 steps from your first AI-built page."

**First action:**
- No fanfare when user creates first page
- Should be: "🎉 You just built your first page with AI! Want to add a contact form next?"

**Error states:**
- Rate limit error is clinical: "You've hit your rate limit"
- Should be: "You're creating so fast you hit Claude's limit! Take a breath, try again in a minute."

**Empty states:**
- Blank chat after history expires = disorienting
- Should show: "Welcome back! Last time you created X. Ready to build more?"

---

## What Good Looks Like

**Strong onboarding arc:**
1. "You're about to skip years of WordPress tutorials"
2. "First, grab your AI key (we'll show you how)"
3. "Now watch this..." → pre-loaded demo
4. "Your turn. Try: 'Add my contact info'"
5. First success = celebration + "What's next?" menu

**Retention hooks:**
- Daily email: "Your site is 60% complete. Add pricing?"
- Weekly digest: "Most-built feature this week: testimonials"
- Progress bar: "5/10 essential pages done"
- Streaks: "3 days building in a row!"

**Content flywheel:**
- Suggest next logical step after each action
- "Users with contact pages also added..."
- Showcase templates: "Popular this week"
- Enable sharing: "Show off what you built"

**Cliffhangers:**
- End sessions with: "Tomorrow, let's tackle your About page"
- Unfinished prompts: "Your homepage hero section is blank..."
- Discovery teasers: "Did you know I can install plugins too?"

---

## Critical Missing Piece

**No story = no stickiness.**

This product thinks it's a tool. It's not.

It's a **co-creation experience**.

User isn't using software. User is **building their dream with a partner.**

Right now: feels like talking to a vending machine.

Should feel like: building a house with someone who cares about the outcome.

**Narrative beats needed:**
- Opening hook: "What's your vision?"
- Rising action: "We're making progress..."
- Climax: "Your site is LIVE"
- Resolution: "Proud of what we built. What's next?"

**Missing throughout:**
- Emotional language
- Shared ownership ("we" not "I")
- Celebration of wins
- Acknowledgment of struggle
- Vision of future

---

## Recommendations

**Immediate (Pre-Launch):**
1. Onboarding tutorial: first 3 actions guided
2. Success celebrations: confetti + "What's next?"
3. Chat history persistence: minimum 7 days
4. Return greeting: "Welcome back! Last time: X"
5. Next-action suggestions after every success

**Post-Launch (v1.1):**
6. Progress tracking dashboard
7. Email retention loop
8. Content recommendations engine
9. Public showcase gallery
10. Achievement system

**Long-term (v2.0):**
11. Collaborative features (share builds)
12. Community templates library
13. Streaks & milestones
14. AI learns user style over time
15. Narrative mode: AI guides full site build start-to-finish

---

## Score: **3/10**

**Justification:** Functional but narratively dead. No story arc, weak retention, zero content strategy, minimal emotional hooks.

Product works. Product doesn't *matter*.

User can create pages. User won't *care*.

Fix the story or watch users churn after first session.

---

## Bottom Line

**You built a chat interface. You needed to build a relationship.**

WordPress is already overwhelming. This plugin should be the guide that makes users feel capable, not another tool that makes them feel lost.

Right now: user asks question, gets answer, leaves.

Should be: user starts journey, makes progress, comes back for next chapter.

**Ship it. But know this:** without narrative hooks, you're fighting 1-hour transient expiry AND zero emotional investment.

That's how you get 20% retention instead of 80%.

The tech is solid. The story is missing.

Make users feel like they're building something *with* someone, not just *using* something.

That's the difference between a plugin and a phenomenon.
